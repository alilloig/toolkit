Box-and-arrow diagram

The canonical pattern for box-and-arrow visualizations (call-chains, flow diagrams): <rect> fills reference role tokens, <line> strokes and <text> fills use currentColor, and the arrowhead <marker> defines its fill once in <defs>.

Callouts

Neutral note. Background is --aside-bg; the lead-in label takes --accent. Border is a hairline on all four sides — never a thick rule on one edge.

Success callout. Background tints to --success-bg; the label takes --success.

Warning callout. Background tints to --warning-bg; the label takes --warning.

Error callout. Background tints to --error-bg; the label takes --error.

A callout with no lead-in label still reads correctly — it carries the tint alone.

Typography & code

Body prose uses var(--fg) against var(--bg). Inline code spans use the dedicated --code-bg / --code-fg pair. Block code:

:root {
  color-scheme: light dark;
  --bg: #ffffff;
  --fg: #1f1f1f;
}
@media (prefers-color-scheme: dark) {
  :root { --bg: #1e1e1e; --fg: #cccccc; }
}
